My work spans front end, back end, build systems, and customer support—delivering secure, reliable products that perform across web, desktop, and mobile environments.

## Front‑end leadership and modernisation (TypeScript / React / Web)

I’ve significantly improved how our front‑end applications are built, maintained, and shipped. Key contributions include:

- Introduced **React Router** to enable full routing, preloading, and streamlined authentication/authorisation flows.
- Standardised form handling using **React Hook Form**, improving developer speed and enabling responsive, reliable validation.
- Improved data fetching and UI responsiveness with **TanStack Query**, enabling robust loading states, caching, and cleaner async patterns.
- Migrated projects from **JavaScript to TypeScript**, shifting many runtime failures into compile‑time checks and improving long‑term maintainability.
- Upgraded build tooling to **Vite**, reducing build times and improving developer feedback loops.
- Created and documented an **in‑house component library** (built with **Next.js**) and established a company‑wide **style guide**, improving consistency, accessibility, and delivery speed across products.
- Designed a scalable **multi‑target build strategy** to support web, desktop, and mobile releases, leveraging **Tauri** and **Rust** where appropriate.
