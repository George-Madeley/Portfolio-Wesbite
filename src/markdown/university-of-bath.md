Throughout my MEng, I built a broad foundation across software engineering, algorithms, machine learning, image processing, parallel programming, and embedded/digital systems. I combined theory with hands-on implementation—often benchmarking performance or measuring accuracy to validate results.

## Algorithms, data structures, and AI (Java)

- Implemented core data structures in **Java** (including lists, binary trees, and string comparison) using **IntelliJ**.
- Built an AI Sudoku-solving agent using techniques such as **depth-first search** and **constraint satisfaction**.
- Performance results: across **60 puzzles** (four difficulty levels), the agent solved **45 in under 1 second**, with the remainder solved in **under 30 seconds**.

## Machine learning (Python)

- Developed and compared multiple ML approaches for tasks including:
  - **EEG signal classification**,
  - digit classification using the **MNIST** dataset,
  - and optimisation-focused experiments.
- Applied techniques including **neural networks**, **genetic algorithms**, and **support vector machines (SVMs)**.
- Achieved **98.8% accuracy** on MNIST using a neural network.
- Designed a genetic algorithm to:
  - solve **polynomial equations**, and
  - optimise **neural network parameters**.

## Image processing and noise reduction (Python)

- Investigated noise reduction methods and their impact on image quality.
- Implemented a suite of filters in **Python**, including:
  - **Gaussian** filtering,
  - **median** filtering,
  - and **Butterworth** filtering,
    then evaluated performance across a range of images.

## Parallel and performance-oriented programming (C)

- Implemented **2D convolution** in **C** and parallelised the workload using **multi-threading**.
- Benchmarked performance across different images and thread counts.
- Compared approaches involving **shared-memory** and **distributed-memory** models to understand scaling trade-offs.

## Embedded / digital systems (Assembly, electronics)

- Designed, implemented, and assessed digital circuits including a **stopwatch** and **digital lock**, using **assembly language** in **MPLAB X**.
- Worked with electrical components to deliver user-oriented behaviour and reliable interaction.
- Adapted to COVID restrictions by developing the design of an **electronic self-driving car** concept that follows a **20 kHz** signal along a taped wire—iterating via simulation and refining the model based on results.
